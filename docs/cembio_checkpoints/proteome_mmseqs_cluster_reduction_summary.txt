Interpretation
--------------
Exact sequence deduplication reduced the dataset only slightly, so exact deduplication alone is not enough to substantially reduce structure retrieval time.
MMseqs2 clustering provides a more useful reduction. The 50 percent identity clustering level gives the strongest reduction and can be used as an exploratory proteome-wide structure retrieval layer.

Decision
--------
Use 50 percent identity clusters for an initial broad structure-search strategy across the full proteome.
Use 70 percent identity clusters for a more conservative intermediate layer.
Use 90 percent identity clusters for fine-grained analyses or high-confidence propagation.
The next step is to map each protein to its 90, 70, and 50 percent cluster representative so structure hits can be propagated from representatives to cluster members.
